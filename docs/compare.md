# 원본·변환 결과 비교 페이지

변환 결과를 사람이 확인할 때 쓰는 정적 페이지다. 섹션마다 원본(왼쪽)과 변환 결과(오른쪽)를 나란히 보여 준다.

## 만들기

```bash
cp -r reference/cms-original cms      # 처음 한 번(cms/는 커밋하지 않음)
npm run compare                       # 전체 → output/compare/index.html
npm run compare -- --file 13168/sub_02_05_어깨탈구.html   # 파일 하나만 다시
```

전체 703개는 20초쯤, 크기는 30MB쯤이다. `output/`은 커밋하지 않는다.

## 보기

`output/compare/index.html`을 브라우저로 연다(파일로 열어도 된다. 서버가 필요 없다).

- **목록**: 파일마다 상태(success/partial/failed)와 섹션 결과별 개수(정상·재분류·블록 순서·원본 보존), 경고 수.
  - 확인이 필요한 순서로 정렬: 원본 보존·블록 순서가 많은 파일 먼저. 섹션이 전부 원본 보존인 파일(대부분 header·slider 같은 비콘텐츠)은 맨 뒤.
  - 필터: 상태, "블록 순서 있음"·"원본 보존 있음"·"재분류 있음", 파일 이름 찾기, 확인한 파일 숨기기.
- **파일 페이지**: 섹션마다 `#번호 적힌 타입 → 변환 타입 [결과]`와 경고, 원본·변환 결과.
  - 결과: 정상 변환 / 설명 분리(본문 앞뒤 설명) / 구조 재분류 / 블록 순서(배치 단순화) / 원본 보존.
  - PC 1100 / 모바일 360 폭 전환. 칸 폭에 맞게 축소해 보여 준다.
  - "확인함" 표시는 이 브라우저(localStorage)에만 저장되고 목록에도 반영된다.

## 알아 둘 점

- 원본 화면은 원본 `cms.css`와 Bootstrap 4.6.2(CDN)로 그린 **근사치**다. 원본 사이트 전용 CSS·스크립트·글꼴은 없다(Bootstrap 버전도 미확인).
- 변환 결과는 호스트 CSS(`reference/host-style.css`)로 그린다. 호스트 페이지의 바깥 여백·글꼴은 없다.
- 이미지는 원본 주소 그대로 불러온다. 상대 경로 이미지(`../img/...`)는 보이지 않을 수 있다.
- 원본·출력 HTML은 스크립트를 실행하지 않는 iframe(`sandbox="allow-same-origin"`)에 넣고, 원본의 `<script>`와 `on*` 속성은 지운다.
- 비교 페이지는 `output/compare/files/...`에서 저장소의 `reference/` CSS를 상대 경로로 읽는다. 폴더째 다른 곳으로 옮기면 CSS가 빠진다.
