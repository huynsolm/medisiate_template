  1. 01

    종합영양수액(아미노산)

    • 증상

      입맛도 기운도 없다 / 자주 피곤하다

    • 효능

      식욕증진 / 피로회복

  2. 02

    뇌기능 영양수액

    • 증상

      두통이 지속된다 / 기억력이 떨어진다 / 머리가 맑지 않다

    • 효능

      두통 감소 / 기억력향상

  3. 03

    노화방지 영양수액

    • 증상

      나이가 더 들어 보인다 / 피부가 탁하고 잡티가 많아졌다 / 몸에 독소가 쌓이는 기분이다

    • 효능

      항노화, 항산화 효과 / 피부색 개선

  4. 04

    염증치료 영양수액

    • 증상

      장이 좋지 않아 설사를 자주 한다 / 몸에 염증이 자주 생긴다 / 근육통이 심하다

    • 효능

      장염 치료 / 염증 치료 / 근육통 감소

  5. 05

    종합 영양수액

    • 증상

      몸이 복합적으로 아프다 / 술이 잘 깨지 않는다 / 스트레스도 받고, 피곤하다

    • 효능

      활력/에너지 충전 / 숙취, 통증 감소 / 스트레스 해소

  6. 06

    수술 후 빠른 회복 영양수액

    • 증상

      수술 후 체력회복이 안돼서 힘들다
      수술 후 몸이 느려졌다 / 수술 부위가 너무 아프다

    • 효능

      수술부위 통증 감소 / 체력 컨디션 회복
